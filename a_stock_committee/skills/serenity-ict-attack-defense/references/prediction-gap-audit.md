# 预测缺口审计

这份审计用于纠正此前回答里容易短视或证据不足的地方。以后遇到“进攻什么”“能不能抄底”“指数破位了吗”这类问题，先过这里的检查。

## 主要短板

1. **容易把当日强弱当成主线**
   - 问题：盘中回答容易从涨幅榜出发，变成“今天涨什么就买什么”。
   - 修正：先问未来 1-12 周什么会被持续重新定价，再看今天强弱是否只是验证。

2. **消息到 A股映射不够硬**
   - 问题：例如 SpaceX IPO、海外半导体、FOMC 利率预期，不能直接推到 A股某只票。
   - 修正：必须拆成“海外事件 -> 产业链层级 -> A股真实收入/订单/客户/产能证据 -> 技术买点”。

3. **产业链卡点和交易买点混在一起**
   - 问题：Serenity 式卡点能说明谁值得研究，但不能直接说明今天能买。
   - 修正：卡点通过后，还要用 ICT/趋势结构确认承接、止损位和入场触发。

4. **半导体抄底缺少溢价和底层资产分层**
   - 问题：看到 ETF 大跌容易误判为便宜。
   - 修正：跨境 ETF 必须同时看场内价格、单位净值/溢价率、底层三星/SK海力士/美股半导体、成交额和换手。

5. **指数破位判断需要收盘确认和宽度确认**
   - 问题：盘中跌破关键位不等于有效破位，但盘中贴近日内低点也不能硬说安全。
   - 修正：区分“盘中破位预警”和“收盘有效破位”；同时看创业板、科创50、深成指、国证2000、涨跌家数和前排题材反馈。

6. **攻防仓位没有按市场状态分层**
   - 问题：只说能不能攻，不够约束仓位。
   - 修正：强修复可主攻；弱修复只轻进攻；退潮只试错或防守。每次必须给总仓位、单票上限和失效后动作。

7. **缺少反方证据和证伪条件**
   - 问题：容易讲顺逻辑，没讲什么情况说明判断错了。
   - 修正：每个主线必须写“降级条件”，例如前排炸板扩散、海外映射证伪、核心中军放量破位、ETF继续杀溢价。

## 两个外部 skill 的边界

### Serenity 的强项和短板

强项：

- 把热点拆成真实需求、系统变化和产业链卡点。
- 逼迫结论回到公告、财报、订单、客户、产能、专利等证据。
- 适合找未来几周到几个月可能反复定价的方向。

短板：

- 不负责盘中买点。
- 容易低估 A股 T+1、涨跌停、后排补涨和流动性踩踏。
- 产业逻辑再强，也可能因为指数退潮或短线拥挤而不能买。

### ICT 的强项和短板

强项：

- 适合处理入场触发、失效位、流动性扫荡、假突破、放量结构。
- 能把“想买”变成“哪里买、错了哪里走”。

短板：

- 不验证公司是否真的受益。
- 不擅长解释政策、产业链、财报和 A股题材持续性。
- 美股/期货 killzone 不能机械搬到 A股；A股还要加 T+1 和涨跌停约束。

## 项目内补齐方式

- `serenity-skill` 负责“为什么这个方向值得研究”。
- `ict-strategy` 负责“什么结构才允许入场”。
- `a-share-committee-orchestrator` 负责“能不能按账户纪律执行”。
- `a-share-execution-risk` 负责“有没有实盘红灯”。
- `position-sizer` 负责“最多买多少”。
- `trader-memory` 负责“以后复盘是否重复犯错”。
