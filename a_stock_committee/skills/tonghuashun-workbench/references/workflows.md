# 同花顺组合分析流程

这些是执行分析的方法，不是已经验证有效的买卖模型。字段阈值、概率和仓位要根据用户问题、样本证据及账户约束确定，不写成通用的“资金流入就买”。入口已按本机帮助定位，但此轮没有逐页点击验证。

## A. 判断强修复、弱修复还是退潮

路径：指数分时/日线 -> 数据看盘76 -> 涨跌分布 -> 涨跌停/炸板 -> 板块94 -> 龙头/中军多窗 -> 成交与资金 -> 收盘复核。

1. 先确认所有模块是同一交易日、同一截止时刻；休市时明确用最近交易日，不把日历“今天”当交易日。
2. 指数：观察是否收复破位点、开盘区间、昨日收盘及关键放量区，区分盘中触及与持续站稳。
3. 宽度：上涨占比、涨跌中位数、跌幅尾部、涨跌停数量、昨日强势股表现。板块拉指数但中位数弱，要降低全面修复判断。
4. 量能：用截至相同时刻成交额与前1/5/20个可比交易日比较；盘中累计不能直接对比昨日全天。收盘再核全天成交额。
5. 结构：主题是否从一两只扩散至龙头、中军和成分股；拉升能否得到回踩承接；尾盘是否回吐。
6. 资金：同源同口径看连续变化与净额/成交额；它是补充，不用来压过价格和宽度的明显反证。

| 证据组合 | 暂定判断 | 反证 |
| --- | --- | --- |
| 指数关键位收复、宽度和领涨群体同步改善、同比时段量能增加且回踩有承接 | 较强修复候选 | 午后回吐、宽度走弱或龙头集体破位 |
| 指数回升但上涨面有限、前期强势股仍弱、量能不足或只有少数权重支撑 | 弱修复候选 | 后续成分扩散且持续站稳，需及时上调判断 |
| 高位负反馈扩大、跌停/大跌尾部增多、反抽难延续、板块接力断裂 | 退潮风险较高 | 大跌后普遍收复关键位且连续改善 |

不采用未经检验的固定“多少家涨停就算强修复”。保留当时快照，次日核验，不用收盘信息改写早盘预测。

## B. 提前识别产业催化，而不只追涨幅榜

路径：资讯/研报 -> F10公告/业务 -> 数据中心 -> 问财/自选 -> 板块成分 -> 多周期与资金 -> 风险雷达。

1. 发现：记录首发时间、原文来源、研究机构/作者、报告日期。转发截图、摘要和付费墙未读全文分别标注；不能说“及时读到摩根研报”却只有二手标题。
2. 差异：新信息相对市场原先预期改变了什么，影响1-12周还是只有当天情绪。技术BOM变化不自动等于上市公司利润增长。
3. 映射：按产品层级查相关公司实际收入、客户认证、产能、良率、交付周期和业绩弹性，区分已公告事实与推断。
4. 预期计价：看事件之前的区间涨幅、估值、成交集中和相对行业走势；不把上涨后才补写的逻辑称为提前发现。
5. 价格验证：板块相对强度、成分扩散、龙头与中军同步性、回踩及成交额。候选可以先入观察池，未触发不强行买。
6. 反证与风控：需求延期、客户否认、业务占比太小、公告风险、扩产兑现滞后、替代技术或行情破位。

AI链分组示例：PCB/钻针、CCL、MLCC、ABF、电源、液冷、光通信/CPO/铜连接、服务器ODM。不要因全属AI就视作同一营收驱动。对每组给“证据/尚未计价部分/拥挤程度/技术触发/失效条件”，而不是一个大而空的看多结论。

## C. 判断高开回落是分歧、承接还是卖压

路径：日K/60分钟 -> 当日与历史分时 -> F1成交明细 -> 盘口/L2 -> 同板块多窗 -> 区间统计。

1. 先定位：高开是否直接到前高、密集成交区、缺口或连续大涨后的压力区域。高开幅度本身不是封板概率。
2. 分阶段观察：竞价结束、开盘第一段拉升、第一次回落、反抽及再次下探，记录量与价格反应。
3. 承接证据：卖出成交增加时价格是否仍能守住/迅速收复结构位，反抽是否有实际成交跟随，板块中军是否同步稳定。单张买一大挂单不算承接确认。
4. 卖压证据：放量下移、反抽缩量、不断形成更低高点和低点，板块转强时它仍弱。描述为可观察卖压，不断言哪个机构出货。
5. 板块强个股弱时查自身公告、前期透支、筹码估算区和相对表现；不要用板块上涨掩盖个股失效。

最终回答包含“当前更支持哪种解释、哪一项数据会推翻它、可卖数量与次日风险”。普通A股当天新买通常不能当日卖，具体证券规则另核；不可建议不可执行的日内止损。

## D. 资金有没有承接、主力是不是跑完

路径：资金流向 -> DDE当日/多日201/202 -> 分时量价 -> 成交明细/L2 -> 龙虎榜96 -> 份额/公告资料。

| 层级 | 可以观察什么 | 不能从中得出什么 |
| --- | --- | --- |
| 一级盘口 | 公开报价、买卖价差、成交和显示挂单 | 全体订单、所有撤单、真实账户身份 |
| L2与逐笔 | 授权范围内更细的委托/成交结构 | 全市场参与者真实持仓及交易目的 |
| DDE/资金统计 | 指定分类模型下净额、净量、连续性 | 国家队持仓、机构都跑完、散户真实户数 |
| 龙虎榜 | 达披露条件时的席位买卖摘要 | 未上榜交易、席位内所有客户身份、当前完整仓位 |
| 定期披露 | 相关报告期末持仓或基金份额 | 未披露期间的实时动作 |

承接分析优先比较：类似卖量下价格冲击是否减小；关键位是否守住并收复；反弹有无量能；相对基准是否改善；买卖价差及挂单补充是否稳定。至少用时间序列，不把一张盘口截图当动态证据。

“大资金筹码出完了吗”的诚实答法是：依据公开数据能否支持卖压减轻/增强，以及还缺什么；不能给无法识别的账户存量编造确定答案。ETF还需将做市和套利考虑进去。

## E. 中韩半导体等跨境ETF为何不跟板块涨

路径：代码搜索 -> ETF资料/F10 -> 跟踪指数与最新持仓 -> 场内分时/成交 -> NAV/IOPV -> 海外市场/汇率 -> 份额与申赎公告。

1. 核对完整基金名称和代码，确认是否真的与比较对象跟踪相同市场/指数。不能以“都是芯片”代替权重分析。
2. 记录中国、韩国等不同部分的实际权重及披露日期；不同交易时段和假期用各自有效报价，不能统一写“外面都涨”。
3. 分解：底层资产变化、人民币汇率换算、场内溢价变化和跟踪误差。对于固定基准净值，价格上涨也可能只是溢价扩张。
4. 优先使用注明时点和计算方法的可比参考价值。过期NAV得出的比值只是相对历史净值，不叫实时溢价；部分跨境IOPV也可能采用滞后价格。
5. 观察二级成交价差、成交额和盘口深度，再查申赎限制、份额变化和风险提示。价格跌而成交额大不等于基金赎回大。
6. 比较未来一两天先做情景：底层修复但溢价收缩、底层下跌但溢价扩张、两者同向。没有数据不能报精确涨跌概率。

近似分解（各项须同时间、同币种、同估值口径）：

`场内收益 = (参考价值_t / 参考价值_0) * (1 + 溢价_t) / (1 + 溢价_0) - 1`

即使底层上涨，溢价收缩也可能抵消收益。此式是恒等分解，不是预测模型；参考价值估错会影响所有归因。

## F. “历史上这种位置/溢价，后面怎么走”

路径：历史K线/分时 -> 当时可用NAV/参考估值与公告 -> 同源数据导出 -> 项目固定样本分析 -> 回到图上检查典型和失败样本。

1. 先定义“这种”：过去N日跌幅、波动率、量比/同比时段成交、趋势、底层指数、溢价区间及资金口径。先定规则再找样本，不能边看结果边改条件。
2. 时间对齐：采用当时已公布的数据，记录NAV所属日期和实际公布时间；盘中参考估值与收盘价格不混用。
3. 同基金样本优先；产品成立时间短、基金转型或指数改变时单独分段。相邻交易日的信号重叠，不能冒充独立样本。
4. 报告样本数、1/2/5日中位收益、上涨比例、尾部亏损、区间和实际成本；同时对比同期无条件基准，做样本外或滚动检验。
5. 找不到可靠历史溢价序列就明确缺口。不得拿后公布净值回填盘中信息，或以形态预测按钮替代统计。

这次软件研究没有运行上述市场回测，不能从本手册推导任何历史胜率。

## G. 持仓分析、做T复盘和风险检查

路径：银河资金股票 -> 当日成交 -> 委托 -> 资金明细/交割单 -> 个股图表/公告 -> 组合风险。

1. 先读真实数量：当前实际持仓、可卖数量、冻结、证券市值、可用资金。股票余额可能显示日初或其他口径，单独不能确定是否还持有。
2. 做T要还原每笔成交的时间、方向、数量、价格和费用。卖过后买回与买入后卖旧仓不同；当前成本价可能包含已实现损益摊薄。
3. 持仓已清零但列表仍有行，不继续建议“持有/止损”。账户现金很高而市值为零，应优先核对实际已卖出的事实。
4. 账户权益与持仓市值、可用资金、冻结资金等对账；无法解释的差额先保留，不靠旧截图填数。
5. 分析总风险集中度：同产业ETF与个股可能重复暴露；跨境ETF再叠加溢价与汇率风险。新增现金不是自动应全买入的理由。
6. 公告风险：监管立案、审计意见、诉讼担保、资金占用、债务、ST/退市、减持解禁、业绩预警等回到原始公告核实。列出发现时间与可能影响，不承诺提前识别所有突发事件。

公开分享分析时脱敏账户与交易明细；本次学习不把用户持仓永久写入公共功能索引。

## H. 股指期货与机构动向

路径：股指/中金所888 -> 具体IF/IH/IC/IM合约 -> 成交量、持仓量、基差 -> 交易所会员持仓排名 -> 现货宽度。

先看排名发布日期，盘中拿不到当日收盘排名时就明确。分合约、分多空、分增减持，区分当月与次月移仓，不把所有期限机械相加。会员是交易通道和客户集合，不等于某机构一个方向的自营判断。

一笔期货交易同时有买卖方；持仓量增加不自动表示净看空。会员净空与市场方向只是条件证据，可能涉及套保、套利与移仓。没有实际排名数据就不报“机构今天加了多少空单”。

## I. 形成一次可执行分析

对用户用短答，详细证据留在本地；不是每次都把所有工具跑一遍。

```text
数据截至：日期、时区、盘中/收盘，哪些字段较旧
当前判断：进攻/观察/防守，或更支持的走势情景
核心证据：价格结构 + 量能/宽度 + 产业/资金证据
反证与失效：具体会改变判断的条件
账户约束：实际仓位、可卖量、可用现金、集中度
下一步：要观察/查询/设置什么；未执行的动作明确标记
```

普通查看页面按只读处理；新增自选、布局或提醒要遵照用户目标并保留原配置。真实委托和条件单不从分析结论自动触发，必须进入另行授权和验证的交易流程。
