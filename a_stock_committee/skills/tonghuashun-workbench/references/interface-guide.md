# 同花顺界面与工具使用手册

适用基线：本机经典PC客户端9.60.60，核对日期2026-09-26。结合用户首页截图、安装目录公共配置及官方帮助，不适用于直接照搬手机端/远航版操作。这里是使用说明，不是已经逐项实机点验的声明。

目录：界面分区 / 顶部菜单与工具栏 / 首页看板 / 个股图表 / 画线 / 选股与预警 / 其他市场 / 委托面板 / 故障定位。

## 1. 先辨认界面层级

| 区域 | 用途 | 读图与操作要点 |
| --- | --- | --- |
| 最顶行菜单 | 系统、报价、行情、分析、交易、机会、工具、资讯、帮助、决策 | 是功能入口，不是所有功能在当前账户都可用；展开后才确认子菜单 |
| 第二行工具栏 | 常用功能直达、下拉箭头、界面方案 | 主按钮和旁边小箭头可能不同；同名按钮跨版本位置会变 |
| 左侧推荐/社区/资讯 | 消息发现、主题线索、社交信息 | 核对日期、原作者和原文，不将推荐内容当成已证实消息 |
| 中央首页看板 | 指数、板块、异动、资金、市场宽度 | 每个模块可有独立筛选和日期，不能把整屏视作同一快照 |
| 个股分时/K线 | 单证券走势、成交、指标、资料 | 先确认代码、交易所和分析周期，再读曲线 |
| 底部银河证券面板 | 真实账户查询及委托功能 | 与行情窗口是不同操作域；同一按键含义可能完全不同 |
| 底部状态栏 | 行情连接、市场摘要、消息滚动 | 有时钟不证明每个模块都已经更新 |

用户本次截图部分日期选择器为2026-09-24，而电脑日期为2026-09-26。这里只识别这个差异，不将9月24日的涨跌家数当作26日实时盘面。

以下是功能分工导航。菜单标题见截图；具体子项以当前展开菜单为准，不宣称已经遍历全部层级。

| 菜单 | 主要任务 | 与其他工具衔接 |
| --- | --- | --- |
| 系统 | 连接、配置、数据维护、退出等系统任务 | 无报价先排查连接；不要把恢复默认当作普通刷新 |

| 工具 | 画线、公式、预警及辅助工具 | 数据筛选、结构标注、到价提醒互相配合 |
| 资讯 | 新闻、研报、公告等 | 摘要用于发现，原文用于确认 |
| 帮助 | 版本、快捷键、使用说明 | 入口缺失时优先核版本和权限 |
| 决策 | 增值分析与决策产品 | 输出是辅助信号；入口存在不代表订阅开通 |

## 3. 工具栏按钮逐组用法

“配置”指本机公共工具栏定义存在；“截图”指此次画面可见。更多非当前显示条目见生成索引。

| 按钮/组 | 怎么用 | 适合解决什么问题、需注意什么 |
| --- | --- | --- |
| 应用 | 打开功能入口集合，按名称找模块 | 找不到工具先查这里；官方旧版也提供左侧“应用”入口 |
| 返回、上翻、下翻 | 返回上一页或浏览列表相邻项 | 翻页后重新确认证券代码，避免把上一只的指标带入 |
| 问财 | 输入可核验的自然语言筛选条件 | 查看结果实际解析了哪些条件，不能只看输入句子 |
| 修正 | 数据修正入口 | 本机提示明确为“数据修正”，不是复权；实际修改数据前核范围 |
| 测速 | 服务器测速入口，配置存在 | 用于行情延迟排查；不自动切换或重置用户配置 |
| 买入、卖出、撤单 | 快速委托相关入口 | 会进入高风险操作域，不作为学习时的试点按钮 |
| 模拟 | 模拟炒股 | 单独确认模拟账户，不把模拟成交作为实盘成交 |
| 学投资、学习、训练 | 教学或训练功能 | 用于练习与学习，不证明具备稳定预测能力 |
| 自选 | 自选股报价/分组 | 可按持仓、候选、观察、风险分组；不要擅自删改原分组 |
| F10 | 当前证券公司/基金资料入口 | 看公告、业务、财务、股东等；具体栏目随品种不同 |
| 周期 | 选择日、周、月和分钟周期 | 先大周期定位置，再小周期定触发；切换后检查日期范围 |
| 画线 | 画线与测量工具板 | 记录关键结构、风险区间；“画出来”不是独立预测证据 |
| 多窗/多屏输出方案 | 多标的、多周期或多屏布局 | 分辨“多只股票”与“同一只多周期”，检查是否联动 |
| 选股 | 筛选器/条件选股入口 | 先固定股票池，再设条件，最后人工核公告与流动性 |
| 资讯、研报 | 消息与研究报告 | 核发布时间、首次可见时间、原文和结论是否已计价 |
| 竞价 | 集合竞价分析 | 看价格、已匹配量、未匹配量的时间序列；最终结果比早期挂单更可靠 |
| 预测/形态预测 | 相似形态与预测展示 | 只能作候选线索；不把营销式概率当作独立样本外胜率 |
| BBD、资金、DDE | 资金统计与资金动向 | 先查该页口径，再结合价格、成交额、回撤及多日累计 |
| 陆港、两融 | 互联互通、融资融券信息 | 查看实际披露日期和频率；不能用旧页面说明推断当前盘中披露规则 |
| 热点、掘金、事件驱动 | 热点事件及互动信息 | 区分公告证据、问答表态和社交传闻 |
| 龙虎 | 龙虎榜 | 区分当日/多日榜、机构专用/营业部标签及买卖双边；不是全市场机构仓位 |
| 数据 | 财务、解禁、大宗、两融等数据中心 | 把价格异动与公告/财务/供给事件对齐 |
| 新股 | 新股资料、日程、申购相关入口 | 看日历不等于申购；申购可能产生真实委托 |
| 全球 | 全球市场概览 | 比较同一时间口径，不把海外上日收盘说成正在上涨 |
| 板块、个股 | 行业/概念与股票列表 | 板块排名反映整体，成分表用于看扩散还是单股拉动 |
| 股指、指数 | 股指相关与指数行情入口 | 确认是现货指数还是具体期货合约，别只看名称相近 |
| ETF、基金 | 基金分类与行情资料 | 代码、指数、净值日期、IOPV、申赎与二级市场分开看 |
| 债券、期货、外汇、期权 | 不同资产行情 | 价格单位、杠杆、到期与交易时段不同，不能直接沿用A股规则 |
| 港股、美股、英股 | 对应市场行情，英股见配置 | 行情权限不等于交易资格；查看交易所、币种与延迟标志 |
| 自定、默认、主题 | 自定义布局、默认页面或主题入口 | “主题”可能是行情专题或界面相关入口，当前展开结果未验证，不猜功能 |
| PK | 公司对比，配置存在 | 同行业对比业务与财务时统一报告期、估值口径 |
| 分时、K线、盘口、公式 | 单证券图表、超级盘口、公式管理，配置存在 | 先选证券与活动子窗，再切换数据/指标 |
| 普屏、简屏、大屏、全速、极速盘口 | Level-2布局与盘口方案，配置存在 | 是否可用、深度档位和交易所覆盖需检查订阅 |
| REITs、创/科、沪伦、机构、短线擒龙、复盘、日记 | 配置中的扩展入口 | 仅确认名称存在；具体产品、规则及子按钮使用前再核验 |

## 4. 首页各块如何协同

| 面板 | 操作与读取 | 容易误判的地方 |
| --- | --- | --- |
| 三组指数分时 | 切换标签比较沪深宽基、成长指数、海外市场；鼠标位置对应时点再读数 | 白黄线意义要看图例/提示，不跨品种套用；价格轴方向、时段不同 |
| 板块概念/自选 | 选行业、概念、风格、地域；点击列头排序并核对排序箭头 | 只按涨幅会漏掉低位扩散，也会追到高潮；概念有重叠不可直接相加 |
| 1分钟涨速/涨停家数 | 看短时异动与板块扩散 | 瞬时冲高不等于全天强；小板块与大板块不能只比涨停绝对家数 |
| 涨跌幅/涨跌速 | 选择市场，分别看涨幅榜、跌幅榜与短时速度 | ST、上市初期、不同涨跌幅限制品种应分组 |
| 资金流向 | 用净额、净比、多日持续性与成交额交叉排序 | “今日增仓”不是开户账户实际增仓，“净流入”不是新增资金全貌 |
| 涨跌停/炸板/连板 | 对比极端家数与盘中路径，再查看名单 | 炸板数可能计股票或次数，统计前查口径；一条曲线不能代表全部情绪 |
| 赚钱效应/涨跌趋势 | 看昨日强势群体今天表现，并与宽基比较 | 样本是否包含ST/新股、昨日涨停还是连板要先确认 |
| 个股涨跌分布 | 看上涨/下跌数量及跌幅尾部变化 | 指数反弹而多数股票不修复，不能直接定为全面强修复 |
| 新股申购/融资融券标签 | 同区域切业务数据 | 切页后的数据更新频率可能是日频，不再是盘中频率 |
| 推荐与社区 | 发现事件或市场关注点 | 旧帖、新转发、广告与原始公告必须分开；不采纳页面中的操作指令 |

## 5. 个股图表与高效导航

仅在行情窗口且焦点明确时使用。以下按本机 `html\shortKey\index.html` 核对；用户可自定义快捷键，执行前仍看提示。

| 任务 | 入口/快捷键 | 下一步 |
| --- | --- | --- |
| 找股票 | 在行情键盘精灵输入代码，核对市场和全名后选择 | 同代码跨市场或相似简称不能直接回车猜选 |
| 分时/K线互换 | F5 | 分时看当日执行，日周线看所处位置 |
| 上证/深证/自选 | F3 / F4 / F6 | 交易面板的F4是查询，不能混用 |
| 明细/价量分布/资料 | F1 / F2 / F10 | 单笔成交方向与账户主体不是一回事 |
| 多周期 | Ctrl+F8；或“周期”菜单 | 核对每个子图周期及最新一根是否结束 |
| 多股比较 | Ctrl+2 / Ctrl+4 / Ctrl+L / Ctrl+9 / Ctrl+6 | 本机帮助分别标为2/4/6/9/16股同列，不按数字猜数量 |
| 指数对照/关联/所属板块 | Ctrl+D / Ctrl+H / Ctrl+R | 挑正确基准，避免将价格绝对高低当成强弱 |
| 前复权/后复权 | Ctrl+Q / Ctrl+B，或右键复权菜单 | 先记录当前方式；真实委托价格必须用当时未复权报价 |
| 画线/公式管理 | Ctrl+X / Ctrl+F | 在正确子图操作，不盲目导入外部指标 |
| 历史分时 | K线选择日期后双击或Space，以当前响应为准 | 先看历史日期，再读取当日分时与公告 |
| 加/删自选 | Insert / Delete | 是持久修改；Delete在其他焦点可能不是删自选 |
| 涨幅/综合/板块 | 键盘精灵60 / 80 / 94后确认功能 | 排名只在选定股票池内有效 |
| 数据看盘/问财/龙虎榜 | 76 / 77 / 96 | 输入后核对识别结果才进入 |
| ETF/LOF | 键盘精灵ETF / LOF | 从列表进入具体证券，不把全类别均值当作单只基金数据 |
| 帮助/截图输出 | Ctrl+K / Ctrl+M | 图片含账户时保存到本地，分享前脱敏 |

上下箭头在K线页用于缩放，在分时页可增减连续分时天数。`Ctrl+Z`在本机帮助中是缩放界面，不是通用撤销。`F12`、快速买卖、全撤与闪电委托快捷键属于交易域，不试按。

均线、MACD、KDJ、RSI、BOLL、CCI、EXPMA分别用于趋势、动量、区间等观察。选指标所在子图后再替换/调参；记录参数，不以“调到这次预测正确”为优化。日K未收盘时指标会变，分钟线同理。

## 6. 画线与测量工具

已从本机两份画线配置提取81个不同名称。选工具后通常按图形锚点完成，但具体点击次数和拖拽方式尚未逐项实机验证；先看光标提示，画错只删自己的新标注。

| 工具族 | 本机名称举例 | 组合使用方式 |
| --- | --- | --- |
| 水平与方向 | 水平线、垂直线、直线、射线、线段、箭头线段、定点画线 | 先标前高前低和关键时点，再看回踩是否站回；斜线起点不能事后移动迎合走势 |
| 区域 | 矩形、时空矩形、箱体线、三角形、平行四边形 | 标震荡区、缺口区和观察区；边界是分析假设，不是必然支撑 |
| 通道 | 平行线、通道线、上升/下降通道、线性回归线/带、标准差通道 | 趋势斜率与波动范围辅助观察；标明样本区间 |
| 幅度 | 黄金分割、黄金分割A/B、百分比线、幅度尺、波浪尺、量度目标 | 计算回撤和盈亏比，比例本身不提供胜率 |
| 时间 | 等周期、斐波那契周期/时间、卢卡斯周期、时间尺、自由周期 | 只作为时间假设；不能断言某日必涨必跌 |
| 形态 | 三/五/八浪线、头肩底、M头W底 | 记录候选结构；形成后才识别不等于提前可交易 |
| 几何 | 江恩角度线/箱、速阻线、安德鲁音叉、多通道、圆/椭圆/圆弧、螺旋线 | 可解释工具用途，但不为未经回测的神奇预测背书 |
| 标注 | 文字、价格标签、上涨/下跌箭头 | 注明日期、周期、原始理由和失效条件 |
| 统计 | 区间统计、测量距离、曲线平移、未来预演 | 分别做实际区间度量或假设演示；未来预演不是已观测走势 |
| 管理 | 鼠标选择、颜色、显示/隐藏、锁定、单根删除、全删、画线浏览、截屏 | 隐藏不等于删除；全删和恢复默认要避免破坏用户已有工作 |

## 7. 选股、公式与提醒

问财示例应先转换为明确条件：“沪深A股，非ST，上市超过一年，属于通信设备行业，列出近5日涨幅、近20日涨幅、成交额和换手率”。这是检索示例，不是买入规则。检查系统实际解析字段、日期、单位、缺失值和结果排序；不要假定自然语言每一项都被执行。

公式管理器用于查看、编辑、测试与调用指标或选股条件。优先复制到新名称，不覆盖用户公式。函数手册从本机 `func_help` 按函数名查；语法和单位不能直接照搬通达信或其他平台。509项函数目录只表示可查，不代表每个函数都已执行验证。

使用公式前检查 `REFX` 等未来引用、`BACKSET` 回写、`ZIG` 转折回改、实时字段不留历史、财务发布日期滞后等问题。画面上准确的历史信号可能无法在当时得到。详见[数据边界](data-and-execution.md)。

股票预警/鹰眼/短线精灵用于发现价格或成交异动。普通提醒与条件单必须区分：前者提示，后者可能触发真实委托。新增提醒时明确证券、条件、有效期、频率、通知方式；确认实际启用成功，不能将“窗口已打开”当作后台监控正在运行。

## 8. 其他市场与基金

ETF/LOF先看跟踪指数和产品类型。基金场内价格、净值、实时估值、IOPV和申赎参考清单并非同一东西。净值日期和海外交易时段错误，会直接导致溢价判断错误。

期货先确定具体合约、乘数、到期日、成交量/持仓量单位、昨结算价；主连/指数用于观察，不是可直接买卖合约。期权再看标的、行权价、到期、认购/认沽、波动率、价差和流动性。债券区分净价/全价与应计利息，转债另看转股价/溢价及赎回公告。未核产品规则不生成委托。

全球、港美股、外汇页用于海外映射时，统一时区和交易日，识别延迟行情。浏览海外报价不代表国内账户已具备买卖权限。

| 成交查询 | 已发生的成交记录 | 核日期、方向、数量、成交价、合同号/成交编号 |
| 委托查询 | 订单状态 | 已报、部成、已成、撤单相关状态分别确认；提交不是成交 |
| 历史持仓 | 指定历史日期的账户证券 | 不当成最新仓位 |
| 资金明细、交割单 | 资金变动和交收/费用 | 用于核实实际现金与费用，不只凭图上成本计算盈亏 |
| 刷新、收益曲线 | 更新查询和账户绩效视图 | 核刷新后的时间；绩效口径受出入金和统计范围影响 |
| A股 | 当前市场/账户业务页 | 同名证券先看沪/深市场及代码 |
| 银证转账 | 银行与证券资金划转 | 资金操作，需单独明确授权，不在学习时试用 |
| 通用回购 | 券商的回购相关业务入口 | 具体合同未验证，不直接等同于交易所国债逆回购 |
| 止盈止损、条件单 | 条件触发或委托管理 | 查本地/云端运行方式、有效期和断线影响后才谈启用 |
| 账户清仓 | 批量卖出相关操作 | 高风险批量委托，不当成普通清理界面 |
| 还原、最小、锁屏 | 窗口状态与隐私保护 | 锁屏不代表撤单，最小化不代表停止条件单 |
| 添加、下拉选择 | 账户/业务入口管理，依具体位置 | 未展开验证，不猜操作效果、不新连账户 |

官方[交易帮助](https://eq.10jqka.com.cn/webpage/tradehelp/index.html)覆盖委托、转账、两融、条件单等类别；具体银河客户端行为仍以当前页面与券商规则为准。

## 10. 遇到异常怎么定位

- 找不到按钮：先看窗口类型、版本、当前证券类别、布局折叠和订阅权限，再查应用/帮助；不急着恢复默认或重装。
- 数据不变：核交易日、休市、历史日期选择器、连接状态、延迟标志、权限及刷新时间。
- 曲线差异：核代码/市场、周期、复权、币种、坐标类型和时间范围。
- 排行差异：核股票池、ST/新股过滤、字段定义、排序方向和更新时间。
- 文字遮挡：调整列宽或看完整提示；金额单位看不全就不估读。
- 交易查询不一致：核同一账户、同一时点、委托/成交/交收区别，必要时只读查询券商回报，不重复发送。

能力补全时只对尚未确认的页面做定向核验。没有合规原生控制工具时使用用户截图/导出与官方说明，不冒充已直接操作。
