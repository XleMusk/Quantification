# VCP 与趋势交易

用趋势和风险边界审查股票。先问“错了在哪里退出”，再问“对了能赚多少”。

## Workflow

1. 判断中长期趋势：价格是否在上升结构中。
2. 判断相对强弱：是否跑赢指数和行业。
3. 检查 VCP：回撤幅度是否逐级收缩，成交量是否收缩。
4. 检查突破：突破日量价是否支持，是否被涨停扭曲。
5. 定义止损：跌破哪个价位说明形态失败。
6. 计算盈亏比和仓位，不能只凭图形冲动买入。
