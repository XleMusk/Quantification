# 宏观赔率与仓位信心

把市场环境变成仓位约束。高信心不是高兴奋，低信心不是看空；它只是决定是否值得承担风险。

## Workflow

1. 检查大盘趋势：沪深300、中证500、创业板、行业指数。
2. 检查市场宽度：上涨家数、创新高/新低、行业参与度。
3. 检查政策和流动性：利率、信用、财政、产业政策。
4. 检查主题质量：领涨是否扩散，还是少数抱团。
5. 将环境分为：进攻、选择性进攻、中性、防守、保存现金。
6. 输出股票仓位上限、单票仓位折扣和等待条件。
