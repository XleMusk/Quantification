# 好生意与安全边际

用企业所有者视角审查交易想法。不要给神谕式买卖结论；输出证据缺口、关键假设、估值安全边际和否决条件。

## Workflow

1. 读取用户的股票研究模板或口头 thesis。
2. 先确认商业模式、利润来源、ROE、现金流、负债和资本开支。
3. 检查护城河是否来自真实结构优势，而不是短期景气。
4. 对估值做逆向推演：当前价格隐含什么增长和利润率。
5. 写出“如果停牌一年还愿不愿意持有”的回答。
6. 给出必须补充的数据，不替用户做最终买卖决定。
