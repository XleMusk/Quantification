# A 股双线并行 V1

更新：2026-09-26。当前版本是可运行的日频策略、历史回放和日终纸面账户，不是已验证盈利的策略，也不是获准运行的实盘系统。

用户新方案替代旧版“首轮只做教学因子”的范围限制。原研究页面、Qlib、投委会和 FinceptTerminal 保留。新数据不写入原缓存。
粘贴材料里的 sandbox ZIP 与独立策略规格未在本机找到；以下数值是本轮明确选择并固定的候选默认值，不冒称来自未读取的附件。

## 运行入口

```powershell
& D:\Quantification\webapp\start.ps1
& D:\Quantification\webapp\stop.ps1
```

默认网页 http://127.0.0.1:5175，API http://127.0.0.1:8765/docs。端口冲突时启动脚本选择其他端口并输出实际地址。
启动 API、因子 worker、交易 worker、前端四个本机后台进程。关闭浏览器不会停止交易 worker；重启电脑后需重新启动，本轮没有添加开机任务。

数据目录默认 `D:\QuantificationData\trading`。在启动前设置 `QUANT_TRADING_HOME` 可替换为其他目录；不是自动迁移旧数据。程序启动后不要单独给某个进程改目录。

```powershell
$env:QUANT_TRADING_HOME = 'D:\QuantificationData\trading'
Set-Location D:\Quantification
& .\env\python.exe -X utf8 -m trading.prepare_data --end 2026-09-26
```

手动刷新应先停止交易 worker，避免两次下载同时切换当前数据指针。每次新下载保存独立版本，完整性与价格检查通过后才发布；失败保留原版本。

## 策略规则

| 项目 | V1 默认值及含义 |
|---|---|
| 股票池 | BaoStock 的 2023-12-29 沪深300历史成分，分别取沪深主板代码排序前5只；固定10股工程池，不是全部A股或动态沪深300策略 |
| 回放区间 | 2024-01-02 至 2026-09-24，共663个交易日；2023年数据仅预热 |
| 资格 | 当日非ST、正常交易、IPO满365个日历日、未到已知退市日期；20日成交额中位数至少2000万元 |
| 动量 | 前复权收盘价 `P[t-21] / P[t-126] - 1`，必须为正 |
| 风险调整 | 上述动量除以最近60个交易日日收益的样本标准差乘 `sqrt(252)`；不使用未来数据 |
| 调仓 | 首个回放交易日收盘生成信号，此后每5个交易日生成目标，下一交易日开盘模拟执行 |
| 排名缓冲 | 已持有且仍合格、排名前8的股票优先保留；空余名额从高分到低分补足，最多5只 |
| 权重 | 每个目标 `min(20%,80%/5)=16%`；候选不足保留现金，不把剩余名额的资金放大给其他股票 |
| 买入 | 目标与持仓的正差额，100股整数手；先卖后买，按现金及总/单只仓位预算裁减 |
| 卖出 | 调仓时跌出保留范围或失去资格；日内已知ST/退市状态额外产生退出意图，不代表一定卖得掉 |
| 未成交 | 本日余单撤销，保留实际持仓和现金；下一次调仓重算，不伪造补齐成交 |
| 无信号 | 空目标形成退出意图；受限持仓保留，不能将无法成交的股票直接从账上删除 |

资金上限约束的是下单预算；之后价格漂移可能使市值比例变化。V1没有额外的盘中止损、指数择时或收益保证。

股票代码：`600000.SSE,600009.SSE,600010.SSE,600011.SSE,600015.SSE,000001.SZSE,000002.SZSE,000063.SZSE,000069.SZSE,000100.SZSE`。
历史成分查询返回更新日2023-12-25，早于本轮回放；这只避免拿今天成分替代过去，不消除小样本和固定截面选择偏差。

## 账户与成交

- `feed.scores -> choose_targets -> advance -> Ledger.submit/fill` 是回放和纸面账户共用路径；前端不执行策略。
- 金额以分记账。报单仅冻结预算，不改变现金/持仓；成交回报才记账。
- 订单状态包括已报、部分成交、待撤确认、已撤、全部成交、拒单；请求撤单不等于已经撤单。
- 买入T+1，当日不可卖；新增行情日到来后可卖。送转股按上市日解锁；零股仅支持一次全部退出。
- 订单键、成交键去重并检查冲突；最低佣金在同一订单的累计成交额上结算，部分成交不重复收取最低佣金。
- 模拟价格为不复权开盘价加减固定滑点；前一交易日成交量的1%为本日容量上限。为测试回报处理，单笔模拟成交拆成至多两个回报；不是逐笔市场回放。
- 停牌、买入ST、开盘涨停买入和开盘跌停卖出均阻断。没有盘口和队列信息，不声称真实可成交。
- 只支持本池已上市满一年的主板普通交易日。非ST10%；ST在2026-07-06前按5%、之后按10%。科创板、创业板、新股无涨跌幅阶段及特殊复牌不适用；异常开盘阻断。
- 按登记日持仓确认权益，在除权日增加送转股和应收分红、支付日到账。分红税预留固定20%；未知日期或不能解释的除权差异阻断，不猜测补值。
- 缺少持仓行情时保留最后标记价并报告过期估值，不虚构清仓。

默认研究成本：双边佣金万三、每单最低5元，卖出税费万五、双边过户费十万分之一，滑点10bp。
它们是可配置实验假设，不是对用户券商收费、税收待遇或实际成交质量的核验结论。滑点反映在成交价中，不重复放入“费用”列；净收益还包含分红税准备金影响。

## 运行和恢复

SQLite WAL 保存配置、账户、委托、成交、事件和每日权益。单交易 worker 文件锁防止双写；每个交易日通过事务一次提交账户和进度。
中途退出回滚未提交交易日，重启继续下一日，不重复成交。暂停状态持久保存；恢复不重置资金。
每个回放锁定不可变数据快照；同参数对照引用原快照，并保持日期、资金、成本一致。比较表只展示已完成运行，未完成结果不混作完整期间排名。
每个纸面账户独立记账，不与其他模拟账户净额合并。未来真实账户只能由一个订单入口写入，不同时启动旧桥接脚本管理它。

日终纸面模式从创建指定日期开始，工作日16:15（UTC+8）后尝试下载已结束交易日的数据，沿相同路径事后模拟开盘成交。它不是盘中实时仿真，不是在开盘时已发送的订单。
无新已结束交易日时等待。数据未齐或下载失败，保留原数据并显示错误；不会把旧回放补记为纸面账户成交。
关闭服务或电脑休眠时不更新，恢复后补处理账户开始日之后尚未处理的已结束交易日。进程需保持运行；未配置Windows开机自启。

## 四个交易页面

- 运行总览：状态、账户日期、权益、现金、费用、持仓、连接状态和数据日期。
- 策略与目标：参数、候选、目标、实际持仓、最近信号与下次信号所需交易日数。
- 订单与成交：近100笔委托/成交、近40条事件；完成后下载完整文件。
- 研究比较：同条件完整回放、分年记录、普通动量和固定排序等权对照。

因子研究原有四个页面仍可使用，不能将其标签平均收益视为组合净值。

## 研究线与券商边界

`signals.from_qlib` 接受 `datetime,instrument,score,available_at`，拒绝决策时点后才可得的分数、缺失可得时间和重复代码。输出候选分数在组合模块之前接入，不向账户直接写订单。
当前界面开放三个规则信号；外部模型分数的UI导入和训练任务尚未接通。`qlib_baseline.json` 记录 Alpha158/LightGBM 的准备配置，状态明确为 `prepared_not_run`；旧数据OHLC异常和缺失证券仍阻断，未声称本轮已训练模型。

`xtquant_adapter.py` 按官方SDK写了连接、资产/持仓/委托/成交查询、报单、撤单及回报边界，并通过替身测试验证“报单成功不等于成交”和断连/未知状态处理。
它未注册为网页执行后端，默认 `live_enabled=False`，没有安装SDK、读取账号、连接MiniQMT或发送真实订单。
当前适配器不具备真实账户完整的持久意图恢复与自动对账放行；尚待用户提供正式接口条件、明确只读授权后核验。实盘启用还需单独验证账户权限、风险上限、接口和监管报告要求。
旧 `bridge/vnpy_strategy.py` 使用期货风格的空头/平仓逻辑，没有复用作本轮A股账户入口。

## 依据与限制

- [XtQuant 官方接口](https://dict.thinktrader.net/nativeApi/xttrader.html)：账户查询、委托、成交、可卖数量与回调分离。
- [Qlib 信号驱动策略](https://qlib.readthedocs.io/en/latest/component/strategy.html)：信号、组合与执行分层参考，不代表本轮复用了完整Qlib撮合。
- [上交所2026交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)和[深交所2026规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)：规则按日期生效，不能无差别套用旧常量。

本轮工程验收和实际结果见 `ACCEPTANCE_20260926.md`。十股、单一固定历史池、日线近似成交、供应商单源公司行动并不足以验证可实盘策略；本轮没有根据回放亏损修改默认策略参数。
