# 16周学习与落地计划

## 目标与投入
每周8–10小时：约2小时课程、2小时阅读与小练习、4–5小时实验、1小时复盘。前8周建立第一份独立研究，后8周扩展验证和模拟运行。这里是学习预算，不是收益时间表，也不是保证所有任务按周完成。

你已有机器学习、机器人与实验研究经验，因此不默认重学全部Python和神经网络；先检查金融统计、时间对齐、交易成本与组合评价方面的缺口。学习内容以“能用自己的话解释、能手算小例子、能改变代码后预测其影响”为标准。

## 研究主线
**新增量价因子，能否在相同模型、数据和交易设定下，改善未参与调参时期的预测与扣成本后的组合表现？**

开始只研究一个市场的日频股票，不混入高频、期权、加密货币、文本大模型与强化学习。默认先用已有、合法可用的数据；尚无数据则只做教学实验并准备数据接口，不编造真实行情。

模拟运行几周只能检查流程和初步稳定性，不能证明长期盈利。课程掌握慢时延长学习时间，不用跳过关键知识换取日期上的“完成”。

## 最少的模型对照
A：相同可用股票范围内的简单基准/等权组合。
B：相同一组因子的Ridge。
C：相同一组因子的LightGBM。
D：C加你提出的新因子。

如果改用Alpha158，须比较“同为Alpha158的Ridge与LightGBM”；不能把不同特征数量的结果差异全归因于模型。每次只改要研究的变量。

## 你必须亲自能回答的6个问题
1. 因子为什么可能预测收益？失效时可能是什么原因？
2. 信号产生时，输入数据真的已经可获得吗？
3. 为什么收益标签从可成交时刻开始？
4. 新因子和原有因子有什么不同，而不只是相关公式换名称？
5. 策略的收益是否来自市场上涨、行业或规模暴露？
6. 扣除实际假设下的成本、停牌/涨跌停等约束后结论是否变化？

## 每周复盘格式
- 本周真正理解的概念与做对的一道小例题。
- 本周只验证了哪一个研究问题。
- 使用的数据与结果文件位置。
- 哪个结论已有证据，哪个只是猜测。
- 下一次最值得做的一个实验。

## 资料与实施分工
本计划是研究建议；课程范围和项目功能来自 `resources.json` 对应官方入口。Codex负责环境、数据处理、实现、测试与复跑；你负责问题选择、经济解释、实验判断与是否继续投入。遇到不会的公式，先解释并给小例子，再写进实验，而不是只收取一张结果图。
