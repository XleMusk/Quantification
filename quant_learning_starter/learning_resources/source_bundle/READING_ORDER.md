# 量化书籍、课程与项目：推荐顺序



核对日期：2026-09-09。顺序为针对你的日频股票因子研究目标给出的建议，不是课程官方难度评级。



**交付说明：本包不含书籍PDF。当前环境无法完成远程文件下载，所附为官方链接、排序清单和下载脚本。**



## 一、书籍



### 1. Quantitative Trading — 2nd edition

作者：Ernest P. Chan

阅读重点：先读研究想法、回测、执行、风险管理；建议第2、3、5、6、7章。

电子版：商业电子书；购买或学校图书馆授权。未找到授权免费全文。

官方入口：https://www.wiley.com/en-au/quantitative-trading-how-to-build-your-own-algorithmic-trading-business-2nd-edition-p-9781119800064



### 2. Python for Data Analysis — 3rd edition

作者：Wes McKinney

阅读重点：第5—8、10—11章：pandas、读写、清洗、合并、分组、时间序列。已有基础可当工具书。

电子版：作者提供免费HTML全文；不是免费PDF。

官方入口：https://wesmckinney.com/book/



### 3. Introduction to Probability — 2nd edition

作者：Joseph K. Blitzstein; Jessica Hwang

阅读重点：条件概率、期望、方差、协方差、大数定律与中心极限定理。按Stat 110所学内容选读。

电子版：作者官网链接至公开PDF；Google Drive下载可能出现确认页。

官方入口：https://stat110.hsites.harvard.edu/

官方链接的阅读地址：https://drive.google.com/file/d/1VmkAAGOYCTORq1wxSQqy255qLJjTNvBI/view

下载目标：https://drive.google.com/uc?export=download&id=1VmkAAGOYCTORq1wxSQqy255qLJjTNvBI（本次未完成下载；服务器可能要求浏览器确认）



### 4. An Introduction to Statistical Learning, with Applications in Python — 2023 Python edition (ISLP)

作者：Gareth James; Daniela Witten; Trevor Hastie; Robert Tibshirani; Jonathan Taylor

阅读重点：第2、3、5、6、8、13章：统计学习、回归、重采样、正则化、树模型和多重检验。

电子版：作者提供免费PDF；本次文件抓取失败，可在官网点击Download ISL with Python。

官方入口：https://www.statlearning.com/

下载目标：https://hastie.su.domains/ISLP/ISLP_website.pdf（本次未完成下载；服务器可能要求浏览器确认）



### 5. Systematic Trading — 2015

作者：Robert Carver

阅读重点：交易规则、预测分数、仓位、组合、交易成本；在做组合回测时阅读。

电子版：商业电子书；购买或学校图书馆授权。未找到授权免费全文。

官方入口：https://www.harriman-house.com/authors/robert-carver/systematic-trading/9780857194459



### 6. Machine Learning for Algorithmic Trading — 2nd edition

作者：Stefan Jansen

阅读重点：第4、5、6、7、8、12章；代码使用second-edition分支。

电子版：商业书；作者提供配套代码，不等于书籍全文免费。

官方入口：https://ml4trading.io/second-edition/



### 7. Advances in Financial Machine Learning — 2018

作者：Marcos López de Prado

阅读重点：完成第一份研究后，按需阅读金融交叉验证、样本重叠、特征重要性和回测偏差。

电子版：商业电子书；购买或学校图书馆授权。未找到授权免费全文。

官方入口：https://www.wiley.com/en-us/Advances%2Bin%2BFinancial%2BMachine%2BLearning-p-9781119482086



### 8. Convex Optimization — Boyd & Vandenberghe

作者：Stephen Boyd; Lieven Vandenberghe

阅读重点：先读第2—5章，关注凸集、凸函数、优化建模、对偶；做组合约束时使用。

电子版：作者主页说明出版社允许在网上公开全文。

官方入口：https://web.stanford.edu/~boyd/cvxbook/

下载目标：https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf（本次未完成下载；服务器可能要求浏览器确认）



## 二、课程（从概念入门到数学进阶）



### 1. Yale ECON252 — Financial Markets — 2011

定位：可选金融通识，最容易开始

重点：第2、4、7、9、11讲：风险、组合分散、有效市场、股票、行为金融。

课程：https://oyc.yale.edu/economics/econ-252

视频：https://oyc.yale.edu/economics/econ-252

说明：课程页Sessions进入每一讲；有公开视频与文字稿。无需整门先学完。



### 2. MIT 15.401 — Finance Theory I — 2008

定位：金融基础主线

重点：Equities → Risk and Return → Portfolio Theory → CAPM and APT → Efficient Markets。

课程：https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/

视频：https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/pages/video-lectures-and-slides/

说明：概念可学；历史案例和制度不能直接视为当前交易规则。



### 3. Harvard Stat 110 — Probability — 公开课程版

定位：概率基础；可与金融课并行

重点：条件概率、随机变量、期望方差、协方差、极限定理。

课程：https://stat110.hsites.harvard.edu/

视频：https://www.youtube.com/playlist?list=PL2SOU6wwxB0uwwH80KTQ6ht66KWxbzTIo

说明：有微积分和矩阵的基本先修要求；配合概率教材做题。



### 4. MIT 18.05 — Introduction to Probability and Statistics — 2022

定位：统计补课资料，不是完整视频课

重点：置信区间、假设检验、Bootstrap、回归。

课程：https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/

材料：https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/classes-reading-and-in-class-materials/

说明：主打讲义、练习、交互材料；概率部分与Harvard不必重复全学。



### 5. Stanford — Statistical Learning with Python — 2023配套课程

定位：统计学习主课；比CS189更适合作为直接实操入口

重点：对应ISLP第2、3、5、6、8、13章。

课程：https://www.statlearning.com/online-courses

视频：https://www.youtube.com/playlist?list=PLoROMvodv4rOzrYsAxzQyHb8n_RWNuS1e

Python实验视频：https://www.youtube.com/playlist?list=PLoROMvodv4rNHU1-iPeDRH-J0cL-CrIda

edX：https://www.edx.org/learn/python/stanford-university-statistical-learning-with-python

说明：理论播放列表名为with R，但作者说明R/Python理论课共用；Python实验看单独列表。edX登录和证书规则以页面为准。



### 6. UC Berkeley CS189/289A — Introduction to Machine Learning — Spring 2026

定位：加深模型与推导；无需与ISLP全部重复

重点：第3、7—10、14讲：学习流程、回归、正则化、偏差与方差。

课程：https://eecs189.org/sp26/

视频：https://eecs189.org/sp26/

说明：从Schedule的Video链接进入；不是每讲都有公开视频。



### 7. MIT 18.642 — Topics in Mathematics with Applications in Finance — Fall 2024

定位：综合应用主课

重点：第1、6、8、9、11、12、13、19、23讲，按项目需要选看。

课程：https://ocw.mit.edu/courses/18-642-topics-in-mathematics-with-applications-in-finance-fall-2024/

视频：https://www.youtube.com/playlist?list=PLUl4u3cNGP601Q2jo-J_3raNCMMs6Jves

材料：https://ocw.mit.edu/courses/18-642-topics-in-mathematics-with-applications-in-finance-fall-2024/resources/lecture-videos/

说明：官方公开视频目录没有第3、22讲，不再把这两讲列成必须观看任务。



### 8. Stanford EE364A — Convex Optimization I — 公开课程档案

定位：进阶选修

重点：凸集、凸函数、最小二乘、二次规划、约束与对偶。

课程：https://see.stanford.edu/Course/EE364A

视频：https://see.stanford.edu/Course/EE364A

说明：在明确需要组合优化时学习；不是因子入门的前置门槛。



## 三、项目（不要同时安装）



### 1. wesm/pydata-book

用途：基础数据处理

项目：https://github.com/wesm/pydata-book

从这里开始：ch05.ipynb—ch08.ipynb；ch10.ipynb、ch11.ipynb

任务：读取数据、合并、分组、滚动计算、保存Parquet。



### 2. intro-stat-learning/ISLP_labs

用途：基础建模

项目：https://github.com/intro-stat-learning/ISLP_labs

从这里开始：第3、5、6、8章Notebook

任务：先用教材数据比较回归、正则化与树模型；迁移金融数据时重新设计时间划分。



### 3. stefan-jansen/alphalens-reloaded

用途：单因子评价

项目：https://github.com/stefan-jansen/alphalens-reloaded

从这里开始：项目README及examples

任务：用自己计算的因子值和正确对齐的价格，产生IC和分组分析。



### 4. stefan-jansen/machine-learning-for-trading

用途：中级研究案例

项目：https://github.com/stefan-jansen/machine-learning-for-trading/tree/second-edition

从这里开始：04_alpha_factor_research；05_strategy_evaluation；07_linear_models；08_ml4t_workflow；12_gradient_boosting_machines

任务：只复用相关章节，不一次安装所有依赖。旧代码需要实际验证兼容性。



### 5. microsoft/qlib

用途：完整研究主框架

项目：https://github.com/microsoft/qlib

从这里开始：examples/benchmarks/LightGBM/workflow_config_lightgbm_Alpha158.yaml

任务：复现基准，再替换数据、加入自己的因子；修改日期、资金、成本和线程。官方数据目前暂停，数据需另行解决。



### 6. microsoft/RD-Agent

用途：最后再接入的自动化研究

项目：https://github.com/microsoft/RD-Agent

从这里开始：fin_factor

任务：已有可信基准后，让Agent提出并测试少量候选；当前Linux、多数场景Docker。



### 选修A. vnpy/vnpy

用途：国内市场与交易系统工程

项目：https://github.com/vnpy/vnpy

从这里开始：vnpy.alpha；examples/alpha_research

任务：先选一个研究示例，随后才考虑模拟交易接口。



### 选修B. QuantConnect/Lean

用途：海外市场、事件驱动回测与交易

项目：https://github.com/QuantConnect/Lean

从这里开始：官方文档及Algorithm.Python

任务：更接近交易流程时再选；开源引擎不代表云服务、CLI或数据全部免费。



### 选修C. pst-group/pysystemtrade

用途：配合Carver研究系统化期货

项目：https://github.com/pst-group/pysystemtrade

从这里开始：docs/introduction.md；docs/backtesting.md

任务：先读架构和回测，暂不接真实资金。



## 四、与16周计划衔接



|阶段|书与课|项目成果|

|---|---|---|

|第1—2周|Chan、pandas；MIT 15.401选段|pydata-book与一个教学因子|

|第3—4周|概率基础、ISLP入门|ISLP实验；真实数据说明|

|第5—8周|ISLP、Carver；MIT回归与组合|单因子分析、Ridge与LightGBM、第一份研究报告|

|第13—16周|按遇到的问题补课|模拟运行；条件成熟再接RD-Agent|



首次只准备第1—2周。电子书和大数据放已有云端目录，不放Git仓库，不下载整套视频。
