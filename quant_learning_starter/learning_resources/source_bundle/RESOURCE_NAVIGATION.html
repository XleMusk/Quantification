课程

1

Yale ECON252 — Financial Markets

第2、4、7、9、11讲：风险、组合分散、有效市场、股票、行为金融。

课程页Sessions进入每一讲；有公开视频与文字稿。无需整门先学完。

官方入口

2

MIT 15.401 — Finance Theory I

Equities → Risk and Return → Portfolio Theory → CAPM and APT → Efficient Markets。

概念可学；历史案例和制度不能直接视为当前交易规则。

官方入口 视频/课程目录

3

Harvard Stat 110 — Probability

条件概率、随机变量、期望方差、协方差、极限定理。

有微积分和矩阵的基本先修要求；配合概率教材做题。

官方入口 视频/课程目录

4

MIT 18.05 — Introduction to Probability and Statistics

置信区间、假设检验、Bootstrap、回归。

主打讲义、练习、交互材料；概率部分与Harvard不必重复全学。

官方入口 讲义与材料

5

Stanford — Statistical Learning with Python

对应ISLP第2、3、5、6、8、13章。

理论播放列表名为with R，但作者说明R/Python理论课共用；Python实验看单独列表。edX登录和证书规则以页面为准。

官方入口 视频/课程目录 Python实验视频

6

UC Berkeley CS189/289A — Introduction to Machine Learning

第3、7—10、14讲：学习流程、回归、正则化、偏差与方差。

从Schedule的Video链接进入；不是每讲都有公开视频。

官方入口

7

第1、6、8、9、11、12、13、19、23讲，按项目需要选看。

官方公开视频目录没有第3、22讲，不再把这两讲列成必须观看任务。

官方入口 视频/课程目录 讲义与材料
