# 给 Codex 的资源准备任务

读取 official_resources.json 和 READING_ORDER.md。这里的顺序是本轮修订版；不覆盖已有项目或旧的16周计划。

本轮只做资源整理和第1阶段准备：

1. 在已有云端工作区选择一个学习目录。不要自动租机、付费或创建新的云资源。
2. 三本允许公开下载的PDF：先运行 download_open_books.py --dry-run，再正常运行。只使用清单中的官方目标；若出现403、登录或Drive确认页，报告失败及官方入口，不寻找盗版替代，不把网页保存成PDF冒充成功。
3. Python for Data Analysis只保留作者免费网页链接，不爬取或重排成完整PDF。四本商业书只保留合法入口；已有正版文件时再放到个人阅读目录。
4. 课程只整理链接及当前学习的讲义，不下载全套视频。MIT18.05为讲义补课；MIT18.642的第3、22讲不列为公开视频任务。
5. 首轮只获取pydata-book里需要的Notebook。可以按文件获取或稀疏检出。不要同时克隆多个大仓库。后续Jansen第二版必须使用second-edition分支。
6. 交付资源清单、实际下载状态和一个基础数据处理练习。没有真实数据时使用明确标记的教学数据；不要声称完成真实行情回测。
7. 重要代码进自己的Git仓库；书籍PDF、数据、虚拟环境和缓存不进Git。保留数据和代码的许可信息。

执行报告必须区分：实际成功、实际失败、尚未运行。当前资源包中的PDF下载状态是失败，不是已完成。
