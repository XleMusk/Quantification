# 教学数据字典

本阶段只有 `source=synthetic`，无行情服务输入、无真实股票或复权记录。

| 字段 | 类型与含义 | 信号时可得 |
|---|---|---|
| date | 无时区的模拟交易日标签；时刻按开盘/收盘语义区分 | 当日 |
| symbol | SYN000 等虚构股票标识 | 是 |
| open | 当日开盘价；任意教学计价单位，非人民币报价 | 开盘后 |
| high / low | 包含开盘与收盘的模拟最高/最低价 | 收盘后 |
| close | 当日收盘价 | 收盘后 |
| volume | 当日整数成交量；任意教学股数单位 | 收盘后 |
| source | 恒为 synthetic | 是 |
| reversal_5 | `-(close[t]/close[t-5]-1)` | t 收盘后 |
| momentum_20 | `close[t]/close[t-20]-1` | t 收盘后 |
| relative_volume_20 | `volume[t]/mean(volume[t-20],...,volume[t-1])`，不含今日量 | t 收盘后 |
| entry_date / exit_date | 日历上的 t+1 / t+6，缺失成交不顺延 | 日历预先给定 |
| forward_open_return_5 | `open[t+6]/open[t+1]-1` | t+6 开盘后；不可用作 t 日因子 |

日历由 `bdate_range` 工作日构造，再删除两个人为休市日（2025-01-22、2025-02-12）。
它只用于练习交易日的相对位置，没有实现法定节假日、时区、竞价、涨跌停等真实市场语义。

生成器使用 NumPy `default_rng(20260909)`：独立隔夜扰动、共同日内扰动与个股日内扰动形成正价格路径，
成交量取独立对数正态整数，随机价差保证 high/low 包含 open/close。没有植入可预测收益因子。
预热后随机移除约 1% 的个股日记录，检验日历对齐；这不等价于真实停牌的生成机制。

计算前扩展为完整 date × symbol 面板。缺失收盘、零/负价格及非有限数不能形成有效价格因子；
收益率窗口比较准确的日历端点，中间缺一日不改变端点日期。量均值要求过去 20 个会话都有量，缺一格则留空。
真实数据中的复权、退市收益、未来信息可得时间和历史股票池都需要 P2 单独验证。

横截面分组先按所有有效当日因子作五分位，再核对未来标签；相同因子值不按股票名称硬拆。
边界重复导致不足五组时跳过该日分组并记录 `insufficient_distinct_bins`。
分组标签平均只代表有观测值成员的描述统计，`n_signals` 与 `n_observed` 展示缺失覆盖。
高组减低组不是已实现的可交易组合，成交成本、净值、回撤和换手均未实现。
