## P2｜真实数据接入（第3–4周）
- [ ] 先用已有授权源；无则列出一个待开通/待提供来源，不同时接三家。
- [ ] 说明标识、交易日历、复权、价格、成交量、历史股票范围和停牌/退市字段。
- [ ] 记录缺失字段造成的限制；只有今日成分股时标为教学/受限样本，不称无幸存者偏差。
- [ ] 先取小样本检查，再决定正式历史范围；数据存云端项目外目录。
- [ ] 分清代码使用许可、数据访问许可和对外分享许可。
完成标准：有一个可重复读取且用途明确的数据集，或清晰说明具体缺哪项。

## P3｜固定特征比较模型（第5–6周）
- [ ] 按交易日期整体切分，先训练、后验证、最后测试；训练标签结束时间早于评价区间。
- [ ] 仅训练期拟合需要估计参数的变换，验证/测试只应用。
- [ ] 同一组特征比较Ridge和LightGBM；有限的验证集调参。
- [ ] 接入Qlib时修改默认时间、股票范围、资金、成本和线程设置，不原样当正式实验。
- [ ] 一旦查看最终测试结果，不再用它反复选因子；已有查看需写明，另保留未来评价。
完成标准：可复现的模型对照，明确改善来自哪个变量。

## P4｜从分数到组合（第7–8周）
- [ ] 先实现简单只做多等权组合和适当基准。
- [ ] 明确调仓频率、权重、成交时间、缺失成交、现金和交易限制。
- [ ] 逐日估值与资金核算；不能把重叠5日标签当成逐日可实现收益。
- [ ] 报告净收益、回撤、换手、成本与基准；无风险利率的Sharpe口径写清。
- [ ] 固定交易路径下提高成本不得提高净收益；价格不变但发生交易应产生费用损失。
完成标准：小例子手算一致；成本和可交易性未实现时不把结果称作实盘可用。
