# 项目目标
为个人独立股票日频因子研究建立最小可用流程。中文说明，优先复用pandas、scikit-learn、LightGBM和Qlib。代码归项目保存；云端运行优先，本地硬盘空间紧张。先读CODEX_START_HERE.md，本轮只做P0、P1。

# 工作方式
- 保留用户已有代码、环境和项目指令；先检查当前目录和资源，不猜测电脑硬件或远程地址。
- 当前已有安全、获授权的操作直接做；不要反复要求确认普通文件编辑。新付费服务、外部上传、真实交易不属于本轮任务。
- 一个独立环境，先做小数据实验；不全量下载课程、模型、数据和多个仓库；只保留资料链接与当前所需文件。
- 不搭多Agent、Kubernetes、仪表盘或无关抽象。不做无依据的海量公式/参数搜索。不在本轮安装RD-Agent、GPU环境。
- 核心检查必须保留：时间对齐和未来信息、训练期拟合、成本/PnL手算。少量明确测试即可，不追求无关测试数量。
- 合成数据和真实数据分目录、分报告；没有执行不写“通过”，没有市场证据不写“盈利”。
- 使用公开或授权资料；付费书只保存正规入口。凭证不入Git，数据不因代码开源就被视为可公开分发。
- 课程示例可改写为Python练习，不假称原课程的官方作业；每个Notebook写清学习目标、关键计算、小例子和3个理解问题。
- 完成后给出已执行命令、真实结果、文件路径和一个下一步；只有确有阻塞才简述缺少的必要条件。
