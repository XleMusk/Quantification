# 给 Codex 的首轮执行指令
请先读取AGENTS.md、LEARNING_PLAN.md、TASKS.md和resources.json。

我的目标是开展独立股票日频因子研究：先看懂计算与评价，再做模型和组合。每周8–10小时，已有机器学习/机器人实验背景；优先云端运行，代码可保存到私有Git仓库；不要为了量化重新塞满本地磁盘。书籍与课程是选读参考，不需要一次下载或学完。

## 本轮只完成P0和P1
1. 只读确认：当前目录、现有Git状态、操作系统、Python、可用内存、磁盘和已有虚拟环境。不能推断本机型号。已有合法远程工作区就使用；没有远程连接时，只在当前目录创建轻量文本/代码，不租服务器、不伪称已远程运行。
2. 整理资源：保留resources.json与READING_LIST.md的官方链接；优先准备MIT15.401、MIT18.05、MIT18.642、Chan、ISLP、pandas和Qlib。Jansen第二版代码必须指向second-edition分支。先下载当前需要且许可允许的小文件；不下载整套视频、付费全文、全市场数据、全部第三方仓库。
3. 环境：优先复用兼容环境，必要时单建quant-research。建议Python3.11作为初始兼容候选，按实际依赖验证后固定版本。首轮仅numpy、pandas、scipy、matplotlib、pyarrow、ipykernel和pytest等必要包；模型阶段再装scikit-learn、lightgbm、Qlib。不要安装CUDA、PyTorch全家桶、Docker或多套回测框架。确需ISLP全套原版依赖时放单独学习环境，不污染主环境。
4. 教学数据：生成一个明确标注synthetic的日期×股票OHLCV小面板，固定随机种子；不把它当真实行情，数据字段说明明确。有已有授权真实小样本可额外读取，但不要改变其来源说明。
5. 第一个实验：计算3个教学因子（过去5日收益取负、过去20日收益、成交量相对过去20日均值），只用于练习，不声称有效。使用交易日历与可用日期，以t日收盘后形成信号、t+1日开盘进入、持有H=5个交易日至t+6开盘退出为教学标签。对缺失交易日不简单按个股行偏移猜执行日期。未来缺失标签保持缺失，不能填0。
6. 评价：按同一天股票横截面计算Spearman Rank IC，constant/样本不足时返回缺失并记录；画分组统计和教学结果，不把重叠5日收益累乘成年化可交易净值。组合回测放P4。
7. 核对：用固定小样本手工对照一个因子和一个收益标签；修改未来价格后过去因子不变化。首轮只做与已实现内容有关的小测试，不扩大成测试工程。
8. 输出：README运行方法、独立环境清单、一个可运行Notebook/脚本、教学结果、测试的实际输出、课程/书籍对应关系、尚未执行事项。在报告开头标注“教学合成数据，不能用于盈利判断”。
